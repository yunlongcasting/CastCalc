# CastCalc 铸算工具箱 · 使用手册 V1.0

（团队试用版 · 2026-08 · 写给铸造工程师，不需要计算机基础）

## 一、这是干什么的

把咱们天天翻手册、按计算器算的三类活儿做成了"问答式小助手"：
1. **浇注系统设计**——输重量壁厚，出浇注时间和直/横/内浇道截面
2. **冒口设计**——输体积面积，出冒口直径高度，还自动校核补缩量够不够
3. **工艺参数速查**——收缩率、加工余量(GB/T 6414)、起模斜度、最小壁厚

每个结果背后的公式都有出处（铸造工艺学/铸造手册/国标），结果供初步设计，投产前按本厂工艺验证。

## 二、第一次使用（约5分钟，比上一个软件还简单）

**第1步 装Python**（装过的跳过；步骤同ScanPathViewer手册：python.org下载→勾选"Add Python to PATH"→安装）

**第2步 下载软件**
- 打开 https://gitee.com/yunlongcasting/castcalc
- "克隆/下载"→"下载ZIP"→解压到任意文件夹
- 👍 顺手点右上角 **Star（星标）**

**第3步 没有第3步**——本软件零依赖，不用装任何东西。

## 三、日常使用：双击"铸算.bat"，跟着问答走

双击后出现菜单：

```
   铸算 CastCalc v0.1 —— 铸造工程计算小助手
  想算什么？
    1 = 浇注系统设计（浇注时间/浇道截面）
    2 = 冒口设计（尺寸/补缩校核）
    3 = 工艺参数速查（收缩率/余量/斜度/壁厚）
    0 = 退出
```

**输入数字→回车**，然后按提示一项项填数就行。算完按回车回到菜单，可以连着算。

### 例1：算一个灰铁件的浇注系统

选1 → 合金选1(灰铸铁) → 重量输100 → 壁厚输15 → 压头输30 → 件高输20 → 位置选2(中注)：

```
合金: 灰铸铁 | 浇注重量: 100 kg | 主壁厚: 15 mm
推荐浇注时间: 13.6 s
平均静压头: 27.5 cm
阻流总截面: 10.77 cm²
截面比方式: 封闭式
直浇道: 12.38 cm² | 横浇道: 11.85 cm² | 内浇道: 10.77 cm²
```

拿着这几个截面积就能去画浇道了。

### 例2：算一个铸钢件的冒口

选2 → 合金选3(铸钢) → 体积输800 → 面积输960 → 冒口类型选2(保温冒口)：

```
合金: 铸钢 | 铸件模数: 0.83 cm
冒口模数(f=1.2): 1.00 cm
圆柱冒口: Ø5.1 × H7.7 cm  (V=160 cm³)
补缩校核(保温冒口): 通过 (富余系数 1.00)
```

**特色**：软件同时按"模数够不够"和"补缩量够不够"两个判据取大者——
薄板件光模数够是不行的，这个坑软件替你把着。想比较普通砂冒和保温冒省多少料，各算一遍即可。

### 例3：速查

选3 → 想查哪个选哪个 → 按提示输尺寸。比如查铸钢收缩率：直接给出受阻1.6%/自由2.0%。

## 四、名词对照（拿不准输什么看这里）

| 软件问的 | 就是咱说的 |
|---|---|
| 浇注总重量（含浇冒口） | 一包铁水实际浇进型里的重量 |
| 浇口杯液面到内浇道的高度 | 压头H0，从杯口液面量到内浇道进口 |
| 铸件在浇注位置的高度 | 合箱状态下铸件型腔的总高 |
| 铸件（热节）体积/散热面积 | 算整件或只算要补缩的热节都行，UG/SW里量 |
| 富余系数 | ≥1补缩够用，越大越保险（也越费料） |

## 五、出问题了怎么办

| 现象 | 办法 |
|---|---|
| 双击bat闪退 | Python没装好（同上一手册：重装勾选Add to PATH） |
| 提示"输入超出适用范围" | 输入的尺寸/壁厚超出了表格范围，查原始手册 |
| 对某个系数有疑问 | 太好了！这正是我们要收集的——群里说，注明你厂里实用值 |
